# IA Prohibée

Dans le cadre des cours de robotique assurés par M. Thomas FIOLET, toute utilisation d'IA générative type LLM (Large Language Model) est prohibée. Quelqu'en soit l'utilisation (génération d'idée, résolution de problèmes, rédaction, correction des fautes d'orthographe, etc.) Ce type d'outil inclut ChatGPT, Gemini, Claude, etc. (liste non exhaustive).

Ce choix est motivé par plusieurs raisons :

 - Déclin des performances congnitives.

 - Impact écologique majeur.

 - Difficulté d'évaluation des performances réelles.

 - Comportements stéréotypés et discriminatoires.

 - Exploitation et travail humain dissimulé.
